📖 还没有 Firebase 配置？点这里看 3 分钟建库步骤（免费、免信用卡）
  1. 打开 console.firebase.google.com → 用 Google 账号登录 → 「添加项目」，名字随便填，关掉 Google Analytics 即可。
  2. 左侧「构建 / Build」→「Realtime Database」→「创建数据库」→ 位置随便选 → 选「以测试模式启动」（或之后到「规则」粘贴下面的规则）。
  3. 项目首页点「</>」（Web）图标添加一个网页应用 → 注册后会显示一段 firebaseConfig = {…} → 整段复制粘到上面①。
  4. 填②房间名 → 点「保存并连接」。把③的邀请链接发给对方即可。
  5. 建议把数据库规则设为（控制台 → Realtime Database → 规则）： { "rules": { "rooms": { "$r": { ".read": true, ".write": true } } } } （仅靠房间名保密；要更严可加身份验证，超出当前范围。）
