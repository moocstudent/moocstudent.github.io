常见问题

你想问的,我们都回答了

AI 改善建议用的是什么模型?数据会被训练吗?
云版本默认用 Anthropic Claude 处理,工单内容只用于实时推理,不会被任何模型用作训练语料 —— 这是合同条款级别的承诺。企业版可以接你自己的 Claude / OpenAI Key,或者用 Ollama / vLLM 自部署的开源模型。
支持私有部署吗?数据完全自己掌控可以做到吗?
可以,企业版提供完整的私有部署方案 —— Helm chart + Docker 镜像,部署到你自己的 K8s 集群,数据库 / 对象存储 / 日志全部在你的网络内。我们提供安装支持但不接触你的数据。
从 Jira / Trello / 飞书项目 迁移要多久?
典型迁移 1-3 天。我们提供 CLI 工具直接拉 Jira 的工单 / 评论 / 附件,重映射字段。 迁移过程中老系统不需要停机,你可以用脚本做增量同步。
移动端是原生 App 还是 Web 套壳?
Flutter 编译的原生 App,iOS 和 Android 各一个 .ipa / .apk。性能跟原生几乎无差, 但开发节奏快得多 —— 这也是为什么我们能做到 Web / iOS / Android 三端始终保持功能对齐。
API 限流是怎么算的?会不会卡到我们集成?
默认每个 token 60 请求/分钟,写操作另外有 10/分钟。超限返回 429 + Retry-After。 团队版可以申请提到 600/分钟,企业版无限。绝大多数集成场景默认配额都用不完。
能不能跟 GitHub / GitLab 双向同步?
可以。我们有官方的 GitHub / GitLab Webhook 集成 —— PR 关联工单、Issue 同步、 commit 自动改工单状态。如果你的代码托管平台没有官方集成,API 也能 30 行写完一个。
是否支持 SSO?有哪些身份提供商?
团队版支持 Google / GitHub / 飞书 / 钉钉 OAuth。企业版额外支持 SAML 2.0 (Okta / Azure AD / Auth0 等) + LDAP / Active Directory。
